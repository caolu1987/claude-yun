本地音频转文字 使用说明
========================

一、使用方法
1. 双击 Start.bat，会弹出一个黑色窗口，并自动打开浏览器页面。
   （第一次启动要加载模型，大约需要 10–60 秒，页面顶部变成绿色“就绪”后即可使用。）
2. 把音频或视频文件拖进页面，可以一次拖入多个文件。
3. 选择音频语言（不确定就选“自动识别”），点击“开始转写”。
4. 完成后点击 TXT 或 SRT 下载；结果也会自动保存在本文件夹下的 output 文件夹里。
5. 用完后直接关闭黑色窗口即可退出。使用过程中请不要关闭黑色窗口。

二、电脑要求
- Windows 10 / 11，64 位。
- NVIDIA 显卡，并已安装较新的显卡驱动（2023 年及以后的版本，需要支持 CUDA 12）。
  驱动下载：https://www.nvidia.cn/drivers/
- 显存建议 4GB 以上；显存较小时会自动改用省显存模式。
- 没有 NVIDIA 显卡也能用，程序会自动改用 CPU 和较小的模型，但速度慢很多。
- 整个过程完全离线，不需要联网，音频不会上传到任何地方。

三、常见问题
- 页面显示“GPU 不可用，已改用 CPU”：
  请先更新 NVIDIA 显卡驱动后重新打开 Start.bat。
- 浏览器没有自动打开：
  手动在浏览器里打开黑色窗口中显示的地址（通常是 http://127.0.0.1:7860/）。
- 杀毒软件拦截：
  本程序只在本机运行，请把整个文件夹加入信任列表。
- 需要强制只用 CPU 排查问题：双击 Start-CPU.bat。
- 识别结果里出现重复句子或乱码：保持勾选“过滤静音”，并在语言里明确选择音频语言。

四、文件夹说明
- Start.bat        启动程序
- Start-CPU.bat    只用 CPU 启动（排查问题用）
- output\          转写结果（TXT、SRT）
- app\             程序代码
- python\          内置的 Python 运行环境
- runtime\cuda\    NVIDIA CUDA 运行库
- models\          语音识别模型（large-v3-turbo 用于显卡，small 用于 CPU）
